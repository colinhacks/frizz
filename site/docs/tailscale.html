Remote access

Tailscale

An HTTPS name on your tailnet, with Tailscale handling TLS. Only devices signed into the tailnet can reach it.

Port setup

Run Tailscale Serve once, in another terminal. It serves Frizz’s default port in the background until you turn it off.

$ tailscale serve --bg 9393

Frizz settings

Press R in the terminal running Frizz, choose Tailscale, and press Enter. Frizz reads this machine’s name from Tailscale and offers it as the origin.

Origin     https://your-machine.your-tailnet.ts.net

Turning it off

Press R and choose Off to put Frizz back on loopback only. This command clears everything the machine serves through Tailscale:

$ tailscale serve reset
