Remote access

Any reverse proxy

Caddy, nginx, ngrok, and other proxies all take the same setup. Terminate TLS wherever you like, proxy to the board’s localhost port, and tell Frizz the public origin.

Frizz settings

Press R in the terminal running Frizz, choose Something else, and enter the exact origin a browser shows. It needs its scheme and no path or trailing slash.

Origin     https://board.example.com

Caddy example

This file also gets the hostname its own certificate:

# Caddyfile
board.example.com {
  reverse_proxy 127.0.0.1:9393
}

Proxy requirements

  • WebSocket upgrades. The board’s live feed is a WebSocket. A proxy that doesn’t forward Upgrade serves the page and then goes silent.
  • No response buffering. The fallback event stream never ends, so a proxy that buffers it shows a board that never updates. In nginx, that means proxy_buffering off.
  • The original Host. Frizz judges the origin from it. A proxy that rewrites it to 127.0.0.1 makes every request look local and skips the sign-in check.

If your proxy can’t preserve Host, don’t put the board on the internet behind it.
