Remote access

Frizz subdomain

An address on frizz.sh that reaches your board from another device. It needs no account, no domain, and nothing installed.

Setup

  1. Press R in the terminal running Frizz.
  2. Choose frizz.sh subdomain.
  3. Scan the QR code with your phone.
Serving https://mk7w2qp9x4n3f6tbz5vh.frizz.sh (frizz.sh).

Scan to sign in on a phone. Single use, expires in 5 minutes. Press L later for another.

Connection

This option needs no Tailscale or Cloudflare Tunnel. Your board stays on 127.0.0.1 and opens one outbound connection to a relay Frizz runs, and visitors’ requests travel down that connection.

  • No inbound port. The board dials out, so a laptop behind any NAT works with no configuration.
  • No DNS record. The relay already answers for every frizz.sh subdomain.
  • Reconnects. The connection comes back after a sleep or a network change.

Your subdomain

Address20 random characters, so nobody finds it by guessing. A first visit still needs a single-use sign-in link.
OwnershipA key on your machine proves ownership, with no account. Copy the key file to another machine to move the subdomain.
Key fileThe file is identity.key, in ~/Library/Application Support/Frizz on macOS and ~/.local/state/frizz on Linux. An older install keeps it in ~/.frizz.
RenewalEvery launch renews it. A subdomain nobody runs for 30 days is released, and someone else can claim it.
Custom namesPaused. A name you pick, like ada.frizz.sh, needs a GitHub sign-in that isn’t set up yet. A board that already has one keeps it, because renewals use only the key.

Terms

  • One per machine. Each machine key holds one subdomain.
  • Lease. Frizz can reclaim any subdomain at any time.
  • Relay. Every request and keystroke passes through a relay Frizz runs, and the sign-in check runs on your machine. To keep a relay out of the path, use Tailscale or your own proxy.
  • No warranty. If you can’t afford to lose access, use a domain you control.

Other devices

Each device signs in with its own single-use link, which gives it a session for 30 days. Press L in the terminal for a new link, or run this from another shell:

$ npx frizz --link
