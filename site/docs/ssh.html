Remote access

SSH port forwarding

Forward the port over SSH, then open http://127.0.0.1:9393 on the client. There is nothing to set up in Frizz.

$ ssh -L 9393:127.0.0.1:9393 you@your-machine
  • No sign-in link. The port is loopback on both ends, so Frizz treats it as local.
  • Nothing exposed. No port opens to the internet.
  • One session. The forward ends with the SSH session, which makes it awkward from a phone. For a phone, use a frizz.sh subdomain or Tailscale.

Sign-in links over SSH

A machine with a remote setup saved can print a single-use sign-in link over the same connection:

$ ssh you@your-machine npx frizz --link
