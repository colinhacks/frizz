The agent console for extreme productivity.

A web app that runs on your own machine. Start as many Claude Code and Codex agents as you like from one browser tab and let them work: the moment one needs you, it becomes a card in a single queue.

Frizz is for you if

  • Terminal UIs feel dated and get in the way of good user experience.
  • Orchestrator apps like Conductor feel overly complex.
  • Switching between sessions to check on agents is tedious.

How it works

Built around one queue.

Agents keep working on their own. You only see a card when one of them reaches something it cannot settle without you.

01The queue

Only the calls that are yours.

A worker runs until it reaches something only you can settle, then asks a question with lettered options, one of them recommended. A click picks an answer and Enter sends it. Nothing shows up just to be dismissed.

02Projects

Every repo, one server.

Every directory you run it in becomes a project with its own board, all on one server. The home page lists them, and the rail down the left switches between them.

03Goal

Point a thread at the finish line.

Give a thread a standing goal. Frizz sends it as a prompt every time the thread rests, on a clock you set, or both, until you switch it off or the agent says it is done.

04Snooze

Not now. Tomorrow at 9.

Park a card for an hour, until tomorrow morning, or until a date you pick. Attach a follow-up prompt and the thread wakes up already working on it.

05GitHub

Issues in, threads out.

Pick issues and pull requests from the composer, and each becomes its own thread. Workers read issues, diffs, and CI on their own. They never comment, label, or merge unless you ask.

What Frizz is not.

Not an agent.

Frizz runs the Claude Code and Codex CLIs you already have signed in, on your own subscription.

Not a cloud.

No account and no telemetry. The server binds to localhost.

Not a worktree manager.

No worktrees, branches, or build steps behind your back.

Remote access

Answer from your phone.

Frizz binds 127.0.0.1. To reach a board from a phone or another machine, press R in the terminal running it and pick how.

Whichever you pick, Frizz does the authenticating. A device has to redeem a single-use sign-in link before it gets in. Press L for a fresh one, npx frizz --sessions lists the devices holding one, and --sign-out revokes one.
