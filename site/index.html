The agent console for extreme productivity.

A web app that runs on your own machine. Start as many Claude Code and Codex agents as you like from one browser tab and let them work: the moment one needs you, it becomes a card in a single queue.

Frizz is for you if

  • Terminal UIs feel dated and get in the way of good user experience.
  • Orchestrator apps like Conductor feel overly complex.
  • Switching between sessions to check on agents is tedious.

Features

Built around one queue.

Agents keep working on their own. A thread shows up in your queue when it has a question, finishes, or needs you to do something.

The queue

Answer questions with a click

An agent that needs a decision asks with lettered options and marks the one it recommends. Click one and press Enter. Anything you typed in the box goes with it.

See the options before you pick

An option can carry its own screenshots, diff, or table, so you compare the real thing inside the question.

Steps only you can do

When something needs you, like a sign-in or a merge, the agent hands you numbered steps with links and one checkbox to say you finished.

Paste a secret safely

An agent that needs a one-time code or token asks in a masked box, and the value never shows up in the transcript.

Snooze a card

Park a card for an hour, until tomorrow at 9, or until a time you pick. Attach a prompt and the thread wakes up working on it.

See what a resting thread is waiting on

When a thread rests on its own work, its card lists what is still running, so a quiet thread never looks stuck.

Agents at work

See what each thread has running

A line above the reply box counts a thread's sub-agents, shells, watchers, timers, and saved files. Hover a count to see the rows.

Open any sub-agent

Each sub-agent opens in its own drawer with its live transcript and model. On a Claude Code thread you can type into it and steer that sub-agent.

Watch pull requests and CI

A thread can watch a pull request and rest. The card shows each PR's checks, and the agent picks the work back up when CI finishes or a review lands.

Set a goal

Frizz re-sends a goal every time the agent stops, on a clock you set, or both, until you switch it off or the agent says it is finished.

Steer a running agent

Send while an agent works and it reads your message at its next step. Or send it to the queue, where each message gets a turn of its own.

Let threads message each other

A worker can send a message to another thread, even in another project. It lands as one line naming the sender, with a link back.

Reading the work

Full-screen threads

Expand a thread and a rail beside it lists its sub-agents, shells, watched PRs, saved files, and the files it edited.

Diagrams, callouts, and diffs

Agent replies render tables, Mermaid diagrams, callouts, collapsed sections, and highlighted diffs.

Screenshots and video in a gallery

Agents show their work as a gallery. Click one to page through full screen, zoom in, and download.

Read files in place

Links to files open in a reader that stays live as the file changes. Select text and press ⌘I to quote it into your reply.

Your setup

Every project on one page

The Console merges every open project into one board, grouped by status or by project.

A home screen of projects

Every project is an icon, badged with how many threads are waiting or running.

Claude Code and Codex, side by side

Pick the agent, model, and effort for each new thread, and run both on the same repo at once.

Start threads from GitHub

Browse issues and pull requests from the composer, select a range, and start one thread for each.

A real phone layout

On a phone, Frizz has a board of tabs, rows you swipe to snooze or finish, and questions answered one at a time in a sheet.

What Frizz is not.

Not an agent.

Frizz runs the Claude Code and Codex CLIs you already have signed in, on your own subscription.

Not a cloud.

No account and no telemetry. The server binds to localhost.

Not a worktree manager.

No worktrees, branches, or build steps behind your back.

Remote access

Use it from your phone.

Frizz binds 127.0.0.1. To reach a board from a phone or another machine, press R in the terminal running it and pick how.

Whichever you pick, Frizz does the authenticating. A device has to redeem a single-use sign-in link before it gets in. Press L for a fresh one, npx frizz --sessions lists the devices holding one, and --sign-out revokes one.
